# Customer demo script

## Opening

“This is a non-classified portfolio domain, but the product pattern is operational: many data points become prioritized, explainable decisions. The point is how quickly AI-assisted development can create the experience while deterministic rules retain authority.”

## Scenario

1. On Overview, identify the four answer areas: performance, exposure, signals, and what changed.
2. Run the scenario.
3. Open CRDO and show the transition from 65 to 90.
4. Explain that the threshold crossing—not a screen refresh—creates the event.
5. Open Ask Atlas and ask why CRDO ranks first.
6. Show Alerts and the cooldown state.
7. Show Analytics, emphasizing portfolio context.
8. Show System, emphasizing provenance and graceful degradation.

## Closing

“The reusable part is not stocks. It is the architecture: normalize facts, calculate locally, rank deterministically, preserve evidence, alert with state, and let AI explain the governed result.”
